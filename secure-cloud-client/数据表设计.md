## 数据库表设计

## 1. 用户表 `sys_user`（可复用 JavaGuns）

| 字段名   | 类型         | 说明         |
| -------- | ------------ | ------------ |
| id       | BIGINT       | 主键         |
| account  | VARCHAR(50)  | 登录账号     |
| password | VARCHAR(100) | 加密口令     |
| role     | VARCHAR(20)  | ADMIN / USER |
| status   | INT          | 状态         |

------

## 2. 文件表 `cloud_file`

| 字段名      | 类型         | 说明                     |
| ----------- | ------------ | ------------------------ |
| id          | BIGINT       | 文件ID                   |
| file_name   | VARCHAR(255) | 文件名                   |
| owner_id    | BIGINT       | 上传用户                 |
| parent_id   | BIGINT       | 父目录ID（支持多级目录） |
| file_path   | VARCHAR(500) | 物理存储路径             |
| file_size   | BIGINT       | 文件大小                 |
| deleted     | TINYINT      | 逻辑删除标志             |
| create_time | DATETIME     | 上传时间                 |

📌 说明：

- `parent_id = 0` 表示根目录
- 不区分“文件 / 文件夹”，文件夹可单独一张表（可选）

------

## 3. 标签表 `file_tag`

| 字段名     | 类型        | 说明   |
| ---------- | ----------- | ------ |
| id         | BIGINT      | 标签ID |
| tag_name   | VARCHAR(50) | 标签名 |
| creator_id | BIGINT      | 创建者 |

------

## 4. 文件-标签关联表 `file_tag_rel`

| 字段名  | 类型   | 说明   |
| ------- | ------ | ------ |
| id      | BIGINT | 主键   |
| file_id | BIGINT | 文件ID |
| tag_id  | BIGINT | 标签ID |

📌 说明：

- 多对多关系
- 搜索时 JOIN 使用

------

## 5. 用户组表 `user_group`

| 字段名      | 类型         | 说明     |
| ----------- | ------------ | -------- |
| id          | BIGINT       | 用户组ID |
| group_name  | VARCHAR(100) | 组名     |
| creator_id  | BIGINT       | 创建者   |
| create_time | DATETIME     | 创建时间 |

------

## 6. 用户-用户组关联表 `user_group_rel`

| 字段名   | 类型   | 说明     |
| -------- | ------ | -------- |
| id       | BIGINT | 主键     |
| group_id | BIGINT | 用户组ID |
| user_id  | BIGINT | 用户ID   |

------
